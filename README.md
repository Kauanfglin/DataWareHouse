Esse projeto visa simular o mercado real de trabalho na área de dados, aplicando na prática conceitos utilizados no dia a dia de empresas que trabalham com Business Intelligence e Data Warehouse.
Desenvolvido como parte prática do curso de Data Science que realizei, o objetivo foi construir um pipeline de dados completo simulando o ambiente de uma empresa de varejo. Ao decorrer do projeto começamos criando o banco transacional com as tabelas de clientes, produtos, pedidos e localidades, inserindo dados com inconsistências propositais para simular um ambiente real. Em seguida construímos a Stage Area, onde copiamos esses dados e fizemos o tratamento deles, limpando e-mails inválidos, padronizando status de pagamento e classificando as lojas por região do Brasil. Com os dados tratados, partimos para a construção do Data Warehouse usando o modelo estrela, criando as tabelas de dimensão de cliente, produto, localidade e tempo, e por fim a tabela fato de vendas centralizando tudo. Durante essa etapa também tratamos os casos de clientes e produtos sem correspondência para garantir que nenhum dado fosse perdido na carga final
